# **London Bike Rides Dashboard**
*Studied project for advanced Tableau visualization - inspired by youtuber Mo Chen*

* [Interactive Tableau Dashboard](https://public.tableau.com/app/profile/aimee.le9707/viz/London_Bikes_Rides/Dashboard1)

## Summary
This project helped me **practice Python data manipulation and Tableau visualization techniques** by analyzing London bike rental data. It reinforced skills in cleaning data, handling categorical and numeric variables, and exploring patterns with plots.

## Key Techniques Learned

* Data loading and inspection with `pandas`
* Cleaning and standardizing columns
* Mapping categorical codes to descriptive labels
* Visualizing trends using `matplotlib` and `seaborn`
* Exporting cleaned datasets for further analysis

## Outcome

* Gained hands-on experience with **data cleaning, exploration, and visualization workflows**
* Built a Tableau dashboard to **visualize bike rental patterns by season, weather, and date**
